# Federated Retrieval Engine

Official code release for "Federated Dense Retrieval over Private Heterogeneous Corpora"
(SIGIR 2026) by Amy Reyes and Sofia Marchetti.

**Status: released.** This is the full, public implementation of the method in the paper,
including the simulation harness and the federated index training scripts.

## Layout
- `src/` — federated index and encoders.
- `data/` — corpus preparation.
- `experiments/` — evaluation harness.
