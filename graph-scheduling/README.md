# Graph Job Scheduler

Source code for "Graph Neural Scheduling for Heterogeneous Cluster Workloads"
(ASPLOS 2027) by Amy Reyes, Daniel Osei and Mei Lin.

**Status: released.** The full implementation, the workload traces used in the evaluation,
and the training/evaluation scripts are included in this directory.

## Layout
- `src/` — graph encoder and scheduler policy.
- `data/` — trace preprocessing.
- `experiments/` — training and evaluation scripts.
